改了什麼

--accent
#d94a2a→#b33a1d
品牌主色：標籤、強調字、按鈕底色
--muted
#8a8278→#736b61
次要文字：日期、規格標籤、placeholder
--accent-on-dark
新增#f07a5a
新增：只用在深色區塊上的 accent 文字

色相不變，只把亮度壓低（品牌紅從 #d94a2a 稍微偏向磚紅）。深色區塊如果也用壓暗的 accent 反而更難讀（4.10 → 2.93），所以另外加一個 --accent-on-dark。

注意事項

  • --accent 全站有 176 處使用，--muted 有 50 處，全部會跟著變色，這也是只改 token 就能一次修好的原因。
  • Ant Design 的主色（#ff4a31，設定在 ConfigProvider）和 --animation-color 是另外設定的，不受影響，主要出現在 admin 後台。
  • Favicon app/icon.svg 寫死 #d94a2a。Icon 不受對比度規範限制，可以維持原色；要統一的話也可以一起換。
  • 這次只掃描了 5 頁，涵蓋全站共用的 LaunchBanner、SiteNav、Footer。Blog 文章頁、/sell 表單和 admin 沒有逐頁檢查，實作時會再跑一次確認。
