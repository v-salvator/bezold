創業成本，指的是從準備開業到穩定營運前所有需要投入的資金。很多第一次創業的人，把注意力全放在裝潢與設備上，卻低估了真正決定生意能不能撐下去的部分：

- 創業成本通常包含「開辦成本」與「營運成本」兩大類。
- 很多人低估的是現金流，而不是裝潢費。
- 創業前先做好完整預算，比找到漂亮店面更重要。

## 什麼是創業成本？

創業成本是指從準備開業到穩定營運前，所有需要投入的資金。很多人只想到裝潢與設備，但真正的創業成本通常還包括：

- 房租與押金
- 原物料
- 行銷
- 人事
- 水電
- 系統與軟體
- 備用資金

換句話說，開店那一刻的花費只是起點，之後每個月的固定支出才是長期壓力所在。

## 創業成本有哪些？

### 1. 店面租金

通常包括押金、第一個月租金與仲介費（如有）。租金應控制在營收可負擔的範圍內，而不是一味選擇最熱門的位置——高租金不代表高獲利。

### 2. 裝潢

不同產業差異很大，早餐店、咖啡店、美甲店與健身房的投入可能完全不同。提醒：漂亮的裝潢，不一定代表好的投資報酬率。

### 3. 設備

例如冰箱、POS、桌椅、廚房設備、冷氣與電腦。若接手成熟店，部分設備通常可以一併承接，能有效降低這筆支出。

### 4. 人事成本

包含員工薪資、勞健保、教育訓練與排班。很多創業者會低估人力成本，尤其是在需要輪班或旺季加人時。

### 5. 行銷成本

很多店花很多錢裝潢，卻沒有預算找客人。建議預留一部分行銷預算，用於 SEO、Google 商家、社群、廣告與內容經營。

### 6. 營運資金

這是最多人忽略的部分。建議至少準備 **6–12 個月的營運資金**，避免店剛開、還沒累積客人，現金就先用完。

## 各產業成本比較

不同產業的初期投入與營運難度差異很大。以下用相對高低做比較，幫助你先建立概念（實際金額依品牌、地區與規模而異）：

| 產業   | 初期投入 | 營運複雜度 | 回本速度（依個案而異） |
| ------ | -------- | ---------- | ---------------------- |
| 早餐店 | 中～高   | 高         | 中                     |
| 咖啡店 | 中～高   | 中         | 中                     |
| 洗衣店 | 高       | 低         | 中～慢                 |
| 美甲店 | 低～中   | 中         | 中                     |
| 飲料店 | 中～高   | 高         | 中                     |

> 表中的「高／中／低」是相對比較，不是實際金額。實際成本會因品牌、地段、坪數與經營方式而有明顯差異。

## 自己開店、加盟、接手店的成本比較

同樣是創業，三種方式的成本結構完全不同。以下聚焦在「成本」的角度來比較：

| 成本項目     | 自己開店 | 接手成熟店 | 加盟       |
| ------------ | -------- | ---------- | ---------- |
| 裝潢成本     | 高       | 通常較低   | 依品牌規範 |
| 設備成本     | 全部購買 | 多數已包含 | 品牌指定   |
| 加盟金       | 無       | 無         | 有         |
| 教育訓練     | 自行摸索 | 視店況     | 品牌提供   |
| 初期試錯成本 | 高       | 中         | 中         |

如果你想比較的不只是成本，而是哪一種方式整體更適合你（含開業速度、熟客與經營自由度），可以參考 [接手店 vs 加盟：哪種創業方式比較適合？](/blog/takeover-vs-franchise)。

## 為什麼很多人低估創業成本？

因為大多數人只問「開店需要多少錢？」，卻沒有思考「每個月需要花多少錢？」。真正讓店倒閉的，通常不是裝潢，而是現金流。

有營收不等於能活下去——房租、人事、水電、原物料與廣告都是固定支出，一旦收入波動太大，撐不到獲利的那一天，再好的生意也會關門。這也是[許多創業失敗的共同原因](/blog/startup-failure-reasons)。

## 創業成本估算公式（Bezold Framework）

要避免漏算，可以用一個簡單的公式把創業成本拆成三塊：

<FeaturedSnippet label="Bezold 創業成本公式">
  創業成本 = 開店成本 + 營運成本 + 安全預備金
</FeaturedSnippet>

其中：

- **開店成本**：裝潢、設備、招牌、租金與押金等一次性投入。
- **營運成本**：人事、房租、行銷、水電與原物料等每月固定支出。
- **安全預備金**：至少預留 6–12 個月的營運資金，用來度過營收尚未穩定的階段。

## 常見錯誤

### 把所有錢拿去裝潢

很多人把 80% 的預算花在裝潢、只留 20% 給營運。比較健康的做法是保留足夠現金，讓生意有時間慢慢成長。

### 沒有行銷預算

開店不是終點。沒有曝光，客人很難主動上門，再好的產品也需要被看見。

### 沒有預留營運資金

真正的挑戰，通常出現在開店之後。沒有預備金，就等於沒有給生意試錯與成長的時間。想進一步了解一家店實際值多少、該投入多少，可參考[店面估值完整指南](/blog/business-valuation-guide)。
